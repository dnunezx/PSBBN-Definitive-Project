## Standing user instruction: never take over the PC

- Never control the user's mouse or keyboard, activate or switch windows, or use UI automation that changes desktop focus or interferes with the user's work.
- Continue authorized work through background tools, command-line interfaces, APIs, files, logs, and debugging connections.
- Screenshots are permitted only when they do not control input, change focus, activate a window, or interrupt the user. If that cannot be guaranteed, use logs instead.
- Do not repeatedly stop the task or ask to use computer control. This preference persists across tasks.
